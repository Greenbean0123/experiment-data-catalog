需要从启动入口重新打开

为保护实验数据，这个页面只接受由本机启动入口打开的会话。程序重启后，旧的浏览器标签也需要重新打开。

  • 浏览器版：再次双击 启动 实验数据目录.cmd，或运行 python server.py --open。
  • 桌面版：关闭窗口后重新打开 Experiment Data Catalog。

已保存的实验记录和附件不受影响。

Open the catalog from its launcher

To protect your data, this page only accepts sessions opened by the launcher on this computer. After the app restarts, older browser tabs need to be reopened.

  • Browser version: run 启动 实验数据目录.cmd again, or python server.py --open.
  • Desktop version: close the window and open Experiment Data Catalog again.

Saved experiments and attachments are not affected.
